Current product evidence01 / Machine identity

This Machine

SPD anchors the experience in the actual system it is observing: machine identity, processor, memory, graphics, storage, and other hardware context.

Current product evidence02 / Evidence

Persistent History

History turns transient sensor readings into evidence that can be reviewed across time instead of disappearing when the moment passes.

Current product evidence03 / Controlled test

Tests that preserve the response

Processor Load Response is the first bounded reference test: baseline, controlled load, recovery, cancellation, and preserved before/during/after evidence.

Development build04 / Display ecosystem

Scenes

Scenes are the visible expression of the same SPD telemetry. They are not a separate sensor engine or a decorative overlay disconnected from machine truth.

Scenes

Machine intelligence worth keeping visible.

A Scene is not a second telemetry system. It is a persistent visual surface for the machine truth SPD already knows.

The Scene ecosystem is being designed so capability tier and Scene ownership remain separate: the software can grow without turning visual expression into an artificial gate.
